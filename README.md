## First Official Skill

### Lead Notification Stack — WhatsApp

Location:

```text
lead-notification-stack-main/torus-skill-lead-notification-stack-whatsapp
```

This skill captures leads from a website or web app, saves them to Supabase, sends email notifications through Resend, triggers an n8n workflow, and sends WhatsApp alerts through Meta WhatsApp Cloud API.

Originally proven on `pricing.torusai.io` Build 7.
